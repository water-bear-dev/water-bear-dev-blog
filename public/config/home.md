- Welcome to **Water Bear Dev Blog**. <br>A lightweight, Markdown-driven site for notes, experiments, and writing.
- **How this works** <br>No database—just files and a static shell. <br>Edit Markdown, commit, and deploy (e.g. to Vercel).
- Start customizing here:

| Task                    | File Path         |
| ----------------------- | ----------------- |
| Modify Global Config    | `config/app.json` |
| Update Homepage Content | `config/home.md`  |
| Import Markdown Posts   | `markdowns/*.md`  |
